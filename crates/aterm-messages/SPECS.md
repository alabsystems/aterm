## 0. Notation used in the statements

- Paths are repo-relative. In the `functions` column, `m::f` names `crates/aterm-messages/src/m.rs`'s `f`.
- **Time.** `Instant` is modelled as ℕ nanoseconds and `Duration` as ℕ ns. `ms(d) = min(⌊d/1e6⌋, u64::MAX)`;
  `secs_up(d) = ⌈ms(d)/1000⌉`; `x ⊖ y` and `x ⊕ y` are saturating subtraction and addition.
- **`Reach`**: the `MessageCenter` states reachable from `MessageCenter::new(log, t)`, where `log` is
  `MessageLog::empty()` or a `replay`/`replay_all` of drained lines, through any finite sequence of public
  operations at injected instants that never decrease: post, restate, resolve, resolve_key_prefix, withdraw,
  withdraw_with, keep_as_record, dismiss, mark_seen, act, settle, commit_rows, quit,
  drain_new_for_persist, drain_shelved_for_persist, carried, seed_carried, raise_next_id,
  after_handoff_commit, merge_reloaded_log, end_carried_rows_the_parent_ended, close_uncarried,
  reword_record, supersede_record, fix_closed, the digest operations (post_later, sync_digest, settle_digest,
  file_digest, clear_digest, adopt_digest, catch_up, act_digest) and `wire::apply`.
- `Glass(c)` = `c.on_glass()` ids, in order. `Queue(c)` = the live rows not on glass, unrevealed rows included.
  `committed` = `c.committed_rows()`. `span(hold)` = the hold's fold span: the severity default for
  Default, d for For(d), the ask's span for Ask.
- `Pres(c,w)` = `c.presentation(w, &char_width, None, Links::Painted)`. `Mot(c,p,t,look)` = `c.motion(p,t,look)`.
  `Drawn(c,p,t,look)` is the integer projection in `tests/motion_review.rs::drawn` (surface cells, fill edge
  in 1/16 cell, readout, eta, fade, glyph; not the `anim` descriptor). `Grid(t)` = `{ c.frame_instant(t) + k·ANIM_FRAME : k ≥ 1 }`.
- `Excerpt_r(c,w)` = `Pres(c,w).rows[r].detail.map(|(_,d)| d)`. `bare(s)` = s without a trailing `…`.
  `Clean(s)` = `s.chars().filter(|c| !text::is_stripped(c))`.
- **Additive measure**: `w(s) = Σ_{c∈s} w1(c)` with `w1(c) ∈ {0,1,2}`. This is the injected
  `&dyn Fn(&str)->usize`: `char_width` is `w1≡1`, and aterm-grapheme's `str_grid_columns` is the host's.
- **Q16**: fractions of `ONE = 65_536`. `ROW` = the Q16 length of the row. `Moving`, `Still`, `graded`
  and `flat` are the `Look` fields.
- `File` = every line `drain_new_for_persist` ever returned, each encoded and decoded once (the
  `exception_fuzz_tests` oracle). `as_decoded(l)` = l with every word clipped to the model caps and empty
  detail lines dropped; today it is `#[cfg(test)]` (`log::tests::as_decoded`) and must become production or
  spec-only code before the codec specs can name it (§5).
- **`ReachT`**: the `ProgressTrack` values reachable from `ProgressTrack::default()` by `observe(t_i, a_i)`
  with non-decreasing `t_i`. Field names (samples, projections, newest, anchor, overdue_grace,
  last_advance, began, advances, held_from, unit, series, total) are those in `progress.rs`.
- `Wire(line)` = `wire::NoticeRequest::parse(line)`.
- The presence specs quantify over a `presence::drive::Desk` and a `presence::Host`; the test seams
  TestHost, TFacts and TSlot stand in for them.
- **Blocking gaps** are the numbers of §7 in the historical development audit
  `docs/AUDIT-trust-for-test-migration-2026-10-15.md`.
  Every spec lists gap 0 (the seal that publishes Clean rows), because none is publishable without it.
- "the center state machine" in the difficulty column means: `&mut self` over `Vec<Live>` and the
  `VecDeque` log ring, String/Vec<String> fields, `Option<Instant>` (aterm_time, cross-crate),
  data-carrying enums (Hold, Retired, Intent), loops over rows, saturating Duration arithmetic.
- Every center spec is a statement over `Reach`, so it needs either a state-machine proof (a type
  invariant on `MessageCenter` that each public method preserves) or a refinement to an existing
  `ty_model!` model: ChromeRegrowFloor, ExceptionsOnce/ExceptionsDigest/ExceptionsEnds, or driver-geometry.

## 5. Implied specs that look wrong, or disagree with the code

1. **`fingerprint-key` is false as the test implies it.** `need_tests::a_fingerprint_fits_the_key_cap_and_stays_distinct` suggests |key| ≤ KEY_CAP and distinct subjects ⇒ distinct keys. `need::Fingerprint::new` clips the family to 24 chars and the cause to 20, so room = KEY_CAP−46 = 2. A long subject then gets keep = room−5 = 0, and the code still appends `~xxxx`: 24+1+5+1+20 = 51 > 48. The doc says this case is 'replaced by the hash alone'; the code does not do that. Distinctness rests on a 16-bit FNV suffix plus a head of ≤12 chars, so collisions exist. The test samples only a short family and cause.
2. **`elapsed-words` is false past 999 h.** `ran_words` caps the number at 999 h, but `elapsed_word_change` still names the next hour, where the words do not change. The test samples only up to ~10 h. Either bound the spec to e < 999 h (as stated) or have `elapsed_word_change` return 'never' past the cap.
3. **The torn-line claim is too strong.** `regression_tests::a_torn_line_glued_to_the_next_never_decodes` and the `log.rs` module doc say a cut 'anywhere' fails to decode. A cut inside `m1\tkind` (before a's `kind=` field is complete), glued to the next line, gives tokens with no `=`; `Fields::parse` presumably ignores them, and the line then decodes as the NEXT record. Harmless (no chimera), but it contradicts 'anywhere'. Read from the code, not run. `codec-torn-line` is stated for cuts after the `kind=` field.
4. **Hash-distinctness asserted as if universal.** `band_tests::band_fp_is_zero_with_no_row_and_moves_only_with_what_it_draws` and `drive_tests::the_paint_key_moves_with_every_term_it_paints_from` assert that a resize keeping the column count, or a frame that draws something new, moves the key. `band_fp` mixes geometry through DefaultHasher and motion through xor-multiply-rotate, then ORs in bit 0, so only probabilistic distinctness holds. Likewise `glass::fingerprint_is_zero_when_empty_and_quantizes_the_fill` ('a whole percent moves it', 'busy flips the key') over FNV. The theorems are the zero laws, oddness and the hover injectivity (`band-repaint-key`, `presentation-fingerprint`).
5. **Test-only code under test.** `animate::easings_hit_their_ends` half-tests `animate::ease_out_cubic` and `animate::bell`, which are `#[cfg(test)]` with no production caller: delete them and their asserts. `progress::rate_is_the_window_secant_and_needs_three_seconds` tests the `#[cfg(test)]` `rate_per_min`, a copy of `project()`, so production `project` has no direct test of its validity gate. `log::tests::as_decoded` is a `#[cfg(test)]` normalizer that `review_tests::codec_survives_random_bytes_and_truncations` and `a_flood_keeps_every_bound` compare against; `logline-codec` needs it as production or spec-only code. `samples_len`/`projections_len` in progress.rs are test accessors to private fields; `track-bounded`, `eta-latch-rule` and `observe-reset-rules` belong as a Trust type invariant over those fields, after which the accessors go.
6. **Stale or inverted prose.** `paint::the_comet_sweeps_the_window_edge_to_edge` still calls the comet 'a fifth of the window' in its assert message; COMET_PERMILLE is 250 (a quarter since ruling 242), and its 0.8–1.4× bound is loose. `attention_tests::the_complete_echo_says_the_finished_form_without_a_reflow` promises `✓ Downloaded aterm v0.92.0  100% done` in its doc, but asserts pct=None and no `done` (ruling 244). `motion_review::an_overdue_eta_stops_promising_under_five_seconds`, `a_stall_repaints_the_bar_even_where_the_eta_slot_starved` and `the_elapsed_clock_survives_a_same_activity_supersede` still describe their bug as current ('Fix: …'); the last cites `0:29`/`0:14` clock readouts that ruling 241 removed.
7. **Index-pinned timing.** `attention_tests::echoes_never_change_the_row_count` encodes its expectation as fixed step indices (held[31], swap(31,34)) on a 50 ms grid, derived from today's echo spans (1440 ms, 1650 ms) and SHRINK_QUIET. Retuning any span silently moves the index. The general statement is `band-hysteresis`.
8. **Weak bounds.** `review_tests::text_shapers_never_panic_and_respect_caps` checks `trim_words` against ≤ cap.max(|s|), weaker than its contract (≤ cap always), so an over-cap regression on short inputs would pass. `progress::eta_latches_only_when_three_projections_agree_over_two_seconds`: the burst half's 'within 10 % of the truth' and 'first ≥ 10 s' describe one hand-picked stream; only the rule half generalizes.
9. **A spec over the whole of `Reach` needs one home.** Every center spec is a statement over every reachable `MessageCenter`. Proving them one test at a time would repeat the reachability argument 40 times. They need either a type invariant on `MessageCenter` that each public method preserves (`center-invariant` is the seed) or a refinement to an existing `ty_model!` model (ChromeRegrowFloor, ExceptionsOnce/ExceptionsDigest/ExceptionsEnds, driver-geometry).

## 6. Proof order (easiest high-value first)

No spec is blocked by gap 0 alone. The list starts with the specs that need only gap 3 (E6 body
widening) beyond the seal, then those that add only gap 1 (non-scalar carriers) for finite tables, and
reaches the center specs only once gaps 1, 2 and 4 have landed, starting with the type invariant that
every center spec reuses.

1. **`geometry-cell-at`** (gaps 0, 1, 3). One line of `usize` arithmetic (`saturating_sub`, `/`, `max`).
   It is an `omega`-class proof, and every pixel-to-cell decision the painter makes goes through it.
2. **`waiter-takes-row`** (gaps 0, 1, 3). A `const fn` over a two-variant enum and a `bool`. It is the
   smallest end-to-end exercise of the enum-match widening that `intent-predicate-table` needs next, and it
   decides whether a wait takes a row at all.
3. **`resurface-backoff`** (gaps 0, 3, 7). A `const fn` while loop with `saturating_mul` and an obvious
   variant. It fixes how long a dismissal holds, and that is the arithmetic core of `digest-refines-the-file`
   (10 tests) and `digest-refinement`.
4. **`intent-predicate-table`** and **`family-prefixes-disjoint`** (gaps 0, 1, 3). These are closed
   enum tables, decidable by evaluation once `&'static str` is a carrier. They retire 5 tests and are the
   lemmas `door-admission-table` (10 tests) is built on.
5. **`eta-words-table`**, **`eta-word-change-exact`** and **`elapsed-words`** (gaps 0, 1, 3, 5). Their
   numeric halves (the quantised n and the change instant δ) are `u64` arithmetic with a five-way case
   split and need no strings. They feed `eta-denotation`, `eta-slot-words` and `motion-deadline-exact`,
   and they force the 999 h fix in §5.2.
6. **`regrow-floor`** (gaps 0, 1, 2, 3, 11, 12). This is the code half of the existing ChromeRegrowFloor
   `ty_model!`, so it is the first proof that a model's invariant holds of the compiled Rust. It retires
   5 tests, and `drive-step-and-floor` uses it.
7. **`glass-title-fault`**, **`sanitize-contract`** and **`wire-split-title`** (gaps 0, 1, 3, plus 5 and 7
   for the scans). These are the string predicates under the whole wire grammar, the message builder and
   `center-invariant`. They are pure, with no `&mut`.
8. **`center-invariant`** (gaps 0, 1, 2, 3, 4, 5, 7, 13). It is hard, but every one of the ~40 center
   specs restates part of it. Proving it once as a `MessageCenter` type invariant, preserved by each public
   method, gives the rest their reachability argument for free.

Deferred: everything with gap 10 (34 specs, the model refinements), gap 11 (17, the generic `Desk`/`Host`
presence engine and generic iterators) and gap 13 (33, closures and the injected `&dyn Fn` measures).
