# aterm-wasm: spec recovery from its 141 unit tests

> The 78 specs below are the crate's migration worklist: each is proved through Trust/Clean about
> the compiled Rust function, then the tests it subsumes are deleted. `predict_api.rs` exports
> `predict_edit_key` (`←`, `→`, Backspace to `Predictor::predict_edit`; `predict_backspace` routes
> through it) and `predict_overlay_cursor` (a state chain's cursor), covered by `predict-off-inert`,
> `predict-no-echo-contexts` and `predict-binding-refines-predictor`. A glyph typed inside a line is
> a shift whose overlay emits `[row, col, codepoint]` triples for both the typed glyph and the text
> it moved. Because the web reads no signed OSC 133 `B` prompt marks and no row below the cursor,
> every `KeySample` passes `input_start: None`, `wrap_pending: Some(Grid::pending_wrap())` and
> `below: None` (so Home, End, Ctrl-A, Ctrl-E and Delete remain unmodelled input).

Source: `crates/aterm-wasm` (read only). Every `#[test]` is mapped across `src/{dirty_band_present_api,
effects_api, lib, messages_api, messages_api_tests, notifications_api, predict_api, scroll_input_api,
scroll_input_api_tests, scrollback_tiers_api, scrollback_tiers_api_tests, facade_api, theme_api}`,
plus the code they reach in the engine crates.

Result: **78 specs**, covering **141 live tests** (plus **1 deleted timing test** in §4).

Most of this crate is a wasm-bindgen facade over aterm-core, aterm-render, aterm-effects,
aterm-messages and aterm-predict. So most specs are refinement or delegation claims ("the export =
the engine's function"), which wait on gap 12 (cross-crate citation). A small set of pure helpers
(`tick_bits`, `band_row`, `ScrollInputState`, `utc_offset_s`, `streak_is_dark`, `json_string`,
`pct_encode`, `dirty_rows_to_bands`, `log_since`, `read_kept`, `selection_range_for`,
`render_tier_capabilities_json`, `whole`, `classify`) are the near-term proof targets.

## 0. Notation used in the statements

- `T`: an `AtermTerminal`. `Reach`: the terminals reachable from `AtermTerminal::new`, `new_registered`
  or `new_from_system` by any finite sequence of exported calls (`process`, `process_str`, `resize`,
  `render`, `scroll_*`, `selection_*`, `set_*`, `note_*`, `notice*`, `messages_*`, `predict_*`,
  `pump_reflow*`, …). Every "∀ T" below ranges over `Reach`.
- `HostState(T)`: everything a frame may depend on. That is the terminal's visible display view (grid
  cells at the current `display_offset`, cursor, selection, modes, live OSC colours), theme, palette,
  fonts and line height, chrome `(pad, head)`, the effects pipeline state, the committed message-band
  rows with hover, details, forced-colour and visibility state, and the sub-row scroll residual. It
  excludes the render-schedule fields (`last_frame_key`, the window cache, `present_bands`,
  `last_present_frac`, `frame_scratch` reuse, the damage tracker).
- `Frame(T)` = `(width, height, rgba)` after `T.render()`. `FullExp(T)` = the rgba that
  `dirty_band_present_api::expand_full(T.win.frame_pixels(), …)` produces from scratch.
- `Gated(T)`: the frame-gate predicate `render()` evaluates: `¬force_full_repaint ∧ ¬effects_active ∧
  pending_reflow = None ∧ last_present_frac = 0 ∧ frac_px = 0 ∧ last_frame_key = Some(FrameGateKey{
  damage_epoch, host_visual_gen, effects_active})`.
- `Pack(p: u32)` = `[p>>16, p>>8, p, 0xFF − (p>>24)]` as `u8`s (0xTTRRGGBB to straight RGBA8).
- `DisplayRow(T, r)`: the engine's display-relative row `r` (the history or live line at absolute index
  `display_origin_absolute() + r`), resolved tier-aware.
- `Twin(line, now)`: the reference reply. A fresh `aterm_messages` `MessageCenter` + `WireGate` is fed
  the same lines at the same instants through `NoticeRequest::parse` / `wire::apply` /
  `wire::press_target`, with the settle/commit/drain/take_due step `notice_at` performs on `Paint::Now`.
- `SAN(s)`: aterm-core `Terminal::format_paste`'s sanitizer: ESC and C1 stripped, bare LF and CRLF
  folded to CR.
- `x'` is the value of field `x` after the call; `f` alone is `ScrollInputState::frac_rows`.
- Constants: `INLINE_REFLOW_MAX_LINES = 20000`, `REFLOW_PUMP_GRACE_RENDERS = 120`,
  `REFLOW_BACKLOG_MAX_LINES = 20000`, `REFLOW_STEP_BUDGET_LINES = 2000`,
  `RENDER_DRAIN_BATCH_LINES = 2048`, `MAX_QUEUED_NOTIFICATIONS = 64`, `JOURNAL_CAP = LOG_CAP`,
  `RESTORE_CAP = 2·LOG_CAP`, `MAX_SEARCH_MATCHES` (aterm-core).
- Function paths are relative to `crates/aterm-wasm/src`; `AtermTerminal::` methods live in `lib.rs`
  unless a module prefix says otherwise.

## 6. Proof order (easiest high-value first)

No spec is blocked by gap 0 alone, so the order prefers the smallest gap set, then the tests retired.

1. **`tick-bits`** (gap 3). A 4-case truth table over two bools; the first proof once E6 admits shifts and
   bitwise OR.
2. **`band-row-arith`** (1, 3) and **`scroll-edge-clamp`** (2, 3). Guarded `usize` arithmetic and two
   comparison-only `&mut self` branches. `band-row-arith` is the base of the band pointer chain.
3. **`scroll-accumulator`**, **`scroll-frac-px`** (2, 3, 14) and **`utc-offset-seconds`** (3, 14). They
   retire 9 tests (the whole scroll lattice) and the module's "float waiver". They are the first users of

4. **`streak-polarity`** (1, 12, 13) and **`tier-capabilities-json`** (1, 12). Trivial bodies whose only
   obstacles are an `Option`/closure and a cross-crate citation.
5. **`json-string-escape`** (1, 3, 7), **`dirty-rows-to-bands`** (1, 2, 7), **`log-journal-cursor`**
   (1, 2, 7). Single-loop string and slice contracts; the first two feed `row-range-json`,
   `notification-queue` and `present-buffer-coherence`.
6. **`pct-encode-equals-control`**, **`read-kept-bounded`**, **`selection-range-projection`**,
   **`cell-under-geometry`**, **`scroll-stamp`**, then **`scroll-input-export`** (retires 5 more by

7. **`present-buffer-coherence`** via its lemmas (a) and (b), then **`present-band-classification`** and
