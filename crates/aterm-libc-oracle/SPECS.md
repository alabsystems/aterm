# aterm-libc-oracle: spec recovery from its 72 unit tests

> Status: migration worklist. Each of the 54 specs below is proved through Trust/Clean against the
> compiled Rust function, and then the tests it subsumes are deleted.

Source: `crates/aterm-libc-oracle` (72 `#[test]` fns across `src/` and `tests/exit_codes.rs`).

Result: **54 specs**, covering **72 tests**. **0 tests are not spec samples**. Three tests also pin
data or formatting that no spec should keep (§4).

## 0. Notation used in the statements

- `∀`, `∃`, `⇔`, `⇒`, `¬`, `∧`, `∨`, `∈`, `∪`, `∩`, `\` (set difference), `Δ` (symmetric difference)
  and `++` (concatenation) have their usual meanings. `⊑` is "is a substring of".
- Test ids are `file::test`, with `file` relative to `crates/aterm-libc-oracle/`.
- **J**: the `aterm_json::Value` model, an inductive `Null | Bool b | Number n | String s | Array [J] |
  Object (ordered map String → J)`. `get(k)` is map lookup and is None on a non-object. Every statement
  about a function that reads JSON text is made over J. Parsing text into J is aterm_json's own spec,
  so citing it is a cross-crate citation (gap 12).
- `Lines(s)` = `str::lines(s)`. `trim_end`/`trim_start`/`trim` are the std definitions. `Occ(s,p)` = the
  number of non-overlapping matches of p in s (`s.matches(p).count()`). `Repl(s,p,q)` = `str::replace`.
- `IdentChar(c)`: c is ASCII alphanumeric or `_`. `Words(s)`: the non-empty maximal IdentChar runs of s.
- **CELLS**: the 4-row const table in `src/cells.rs`, rows `(triple, key, os, arch, source)`:
  `mac` = (aarch64-apple-darwin, `darwin_aarch64.rs`), `macx` = (x86_64 darwin, `darwin_x86_64.rs`),
  `linux` = (x86_64-unknown-linux-gnu, `linux_gnu_x86_64.rs`), `linuxa` = (aarch64 linux gnu,
  `linux_gnu_aarch64.rs`).
- **RD(doc)**: a rustdoc JSON document `{root, index (id text → item), paths}`.
  `item(id) = index[id_key(id)]`, where `id_key(Number n) = decimal(n)`, `id_key(String s) = s`, and any
  other id has no key. `kind_of(item)` is the first `(kind, payload)` member of `item.inner`.
- **Public(doc)**: the `BTreeMap name → Namespace → Entry{kind,item}` that `Doc::public` returns.
  `Namespace::of` maps struct, enum, union, type_alias and trait to Type, maps function, constant and
  static to Value, and maps every other kind to None.
- `sig_types(e)`: the types a signature mentions (`closure::signature_types`). For a constant or a
  type_alias it is `[type]`; for a function, the inputs plus the output when present; for a struct or a
  union, each field's `struct_field`; otherwise `[]`.
- **Outcome**: `cargo::Outcome {success, code, errors: [Diagnostic], passed, failed: [FailedTest], stderr}`.
- `ErrList(xs)` = `join("\n", [trim_end(e.rendered) | e in the first 5 of xs] ++ (["... and {|xs|-5} more
  errors"] if |xs|>5))`. `Outcome::detail` and `probe::unmeasured_because` each hold a copy of it
  today (§5.10).
- `ENOSPC` = `"No space left on device"`. `FOUND` = `"expected an array with a size of 999999, found one
  with a size of "`. `BODY_MARKER` = `"type fd_word = "`, the start of the first line of code `regen::shim::bodies` writes (from the constant), never a comment.
- `up(x,a)` = `ceil(x/a)·a`, for `a ≥ 1`; `layout::up` panics when `a = 0`.
- F: the filesystem state. A spec that names F is effectful (gap 8).
- **Gaps** are the rows of `docs/AUDIT-trust-for-test-migration-2026-10-15.md` §7. Gap 0 (an installed
  seal that publishes Lean-discharged rows) comes before every proof, so it is listed on every spec.
  Gap 6 (publication of plain-Rust clauses) applies to any spec discharged on the SMT lane instead of
  in Lean. It is left out of the column because the lane is chosen per proof.

## 5. Implied specs that look wrong, or disagree with the code

1. **Test census overcount.** The census reported 76 tests, but there are 72 `#[test]` fns. The other 4
   are the text `#[test]` inside string literals in `src/regen/oracle.rs`: two `format!` strings in
   `emit()` (lines 857 and 863) and two expected lines in `each_kind_is_pinned_in_its_strongest_form`
   (lines 979 and 986). The census should count only an attribute that begins a line.
2. **A test checks a copy of the production predicate.**
   `src/controls.rs::a_symbol_control_needs_its_own_mismatch` writes its own copy of the LinkName
   `caught` closure, which production keeps inline in `controls::run` (lines 718-722). It tests
   `diff_verdict` plus that copy, never the real closure. **Lift the closure into a named fn** so that
   `diff-verdict-and-header-match` binds to the real one (becomes-spec-after-fix for that half).
3. **An all-underscore integer is accepted.** `regen::shim::integer_value` accepts a `[0-9_]` run made
   only of underscores: `_` or `__i32` gives `Some("")` and `-_` gives `Some("-")`, which emits an invalid
   constant initialiser. `constants_keep_literal_source_else_write_the_evaluated_value` never samples
   this. `shim-const-expr` should require at least one digit; fix the code to match.
4. **The JSON fallback is not escaped.** `verdict::Report::to_json` formats the serde error into
   `{"verdict":"could_not_run","error":"{e}"}` without escaping it. An error message with a quote or a
   backslash gives invalid JSON, so "the fallback is JSON" holds only for escape-free messages.
   `report-json-shape` states the guarded form; escape `e` to make it unconditional.
5. **"No overlap", not "aligned".** `layout::check` (stripped branch) and `shim::padded` only test
   natural > measured. That catches overlap and too-early placement, but a measured offset after the
   natural one that is not a multiple of the field's alignment passes. The comment in
   `src/regen/layout.rs::a_stripped_layout_places_public_fields_at_their_measured_offsets` ("`b`
   measured where it would be misaligned") actually exercises overlap (2 < natural 8).
   `layout-validate` and `shim-struct-layout-reproduces-measurement` state no-overlap. Fix the comment,
   or add the alignment check.
6. **Unstated preconditions.** `layout::up(x, 0)` panics (`div_ceil` by zero), and
   `layout(..., packed=Some(0))` reaches it; `offset + size` and `div_ceil·align` can overflow u64. No
   caller passes such values today, but no-panic needs them as `requires` clauses on `repr-c-layout`.
7. **Two places match trait paths differently.** `decls::derivable_traits` compares `impl.trait.path`
   text exactly against bare names, while `shape::trait_records` matches the last segment of the
   canonical path. A qualified `trait.path` (`core::clone::Clone`) would drop the derive from the shim
   while the shape gate still expects it. The tests use bare names in both places. **Unify on the
   last-segment rule.**
8. **`Measured::record` is not atomic.** On a Byte error it returns Err after the earlier facts are
   already inserted. That is harmless where callers abort on Err, but the `is_err` check in
   `the_compilers_reports_are_read_back_to_their_facts` says nothing about the state left behind.
   `probe-readback` states the partial effect.
9. **The scanner's word grammar is not "identifiers".** `closure::named` starts a word mid-token after a
   digit (`0x40` gives `x40`) and picks up ABI strings (`C` from `extern "C"`);
   `identifiers_skip_builtins_keywords_and_primitives` pins `C` as a found identifier. This is harmless
   only because `closure()` intersects the result with `dom(public)`. `named-identifiers` states the
   actual grammar.
10. **One rendering, two copies.** `Outcome::detail` and `probe::unmeasured_because` each build the
    "first 5 errors, then '... and N more errors'" text. Factor out `ErrList` (§0) as one function so
    one lemma serves both specs.
11. **`names("")` is true.** `Diagnostic::names` splits on non-IdentChar and compares pieces, so the
    empty ident matches whenever a text has adjacent, leading or trailing separators. No caller passes
    `""`, but the intended spec is `ident ≠ "" ∧ ident ∈ Words(t)`; add the guard or a `requires`.
12. **Golden-text residue.** `src/regen/shim.rs::a_cell_module_writes_each_kind_in_its_section`
    and `src/regen/oracle.rs::each_kind_is_pinned_in_its_strongest_form` pin exact emitted lines,
    including comment, header and whitespace lines. The specs keep only the structure (§4).
