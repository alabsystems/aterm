## 0. Notation used in the statements

- `Bytes(a)` = `a.as_ref().as_bytes()` for any `A: AsRef<OsStr>`. This is the input to
  `Arg::with_c_str`.
- `Sys`: an abstract POSIX platform model (gap 8, Lean `PlatformSpec`). It is a state of
  inodes and directory entries plus a per-thread `errno`. Each `*at` call is a relation
  `Sys → (ret, Sys')`. The kernel facts the tests also sample live in `Sys`, not in this
  crate: hard links share `(dev, ino)`, `O_NOFOLLOW` refuses a final symlink, and `NAME_MAX`
  is 255. The crate's obligation is to be a faithful pass-through to `Sys`.
- `Pass(w, call)`: wrapper `w` turns each name through `Arg::with_c_str`. It then makes
  exactly **one** libc `call`, passing the caller's raw fd(s), the C name(s), `flags.bits()`
  and `mode.bits()` unchanged, and it makes no other syscall that resolves a name. It returns
  `Ok(v)` iff `ret >= 0`, where `v = OwnedFd::from_raw_fd(ret)` for `openat`. Otherwise it
  returns `Err(Errno(errno read right after the call))`.
- Flag newtypes `F ∈ {OFlags, AtFlags, Mode}` (generated by `flags!`) and `RenameFlags`:
  `bits(x) = x.0`.
- `Obs_tree(root)`: the recursive snapshot `(name, kind, mode & 0o7777, nlink, size)` that
  the tests compare.
- `Identity(fd)` = `(fstat(fd).st_dev, fstat(fd).st_ino)`.
- `Names(D)`: the multiset of entry names of directory inode `D` in `Sys`, including `.` and
  `..`.
- **Pure core.** Only these parts can be proved without gap 8: `Arg::with_c_str`, the flag
  algebra, `FileType`, the `Errno` constants, `RenameFlags::contains`, and the flag
  translation inside `renameat_with`. Every other spec is blocked by gap 8 (effects, FFI,
  `unsafe`).

## 3. Coverage

- 15 tests read. 14 map to one of the 11 specs; 1 is not a spec sample (§4).
- The biggest collapse is `syscall-passthrough`: 3 primary tests and a secondary role in 5 more.
- `flags-bit-algebra` and `filetype-predicates` retire no test alone. They are the pure lemmas
  that make the differential tests' flag words and kind checks meaningful, and they are the
  cheapest rows to certify.
- Every test here is a differential run against `std::fs` on a real kernel. A spec stated
  over `Sys` proves that the crate passes calls through faithfully. It does not prove that the
  kernel behaves like `Sys`. Deleting a test whose spec is Certified moves the kernel half of its
  evidence into `Sys`'s axioms (gap 8's FFI assumption channel), so those axioms must be named
  and reviewed when the tests go.

## 5. Implied specs that look wrong, or disagree with the code

1. **`a_removed_directory_reads_as_empty` may hold only on Darwin.** The code reads a removed
   directory as empty only when `openat(fd, ".")` fails with `ENOENT` (`Dir::read_from`), which
   is what Darwin does. On Linux, opening `.` of a deleted directory most likely succeeds, and
   `getdents` on a dead directory returns `ENOENT`. Then `next()` would yield
   `Some(Err(ENOENT))` and the test would see `Failed(ENOENT)`, not `Names([])`. Either the test
   is macOS-only in practice, or `Dir::next` must also map an `ENOENT` from the first `readdir`
   to end-of-stream. Not run, so this is unconfirmed. The spec `dir-removed-reads-empty` is
   stated only for the code path that exists.
2. **The Chmod harness covers user bits only.** In `renames_links_and_modes_agree`, the
   `run_mine` Chmod arm rebuilds the mode from bits 0o400/0o200/0o100 alone. The std arm applies
   `Permissions::from_mode(bits)` in full. The two agree only because the script uses user-only
   bits (0o400, 0o600). A group, other, setuid or sticky bit would make the harness itself
   disagree. So the test samples `fchmod` on the user-bit subset, and its reference is not
   faithful for `fchmod` in general. `syscall-passthrough` states the whole mode.
3. **The heap path of `with_c_str` is seen only on failure.** In
   `names_across_the_stack_buffer_boundary_agree`, every length ≥ 256 (past `NAME_MAX` = 255)
   fails in the kernel with `ENAMETOOLONG`. So the heap path (len ≥ 512) is checked only as
   "same errno". A heap path that mangled the name would pass. The real property, that the C
   string equals the input bytes on both paths, is `arg-cstr-faithful`.
4. **Half of `the_not_found_errno_is_the_same_constant` is a tautology.**
   `Errno::NOENT.raw_os_error() == libc::ENOENT` holds by definition (`NOENT = Self(libc::ENOENT)`,
   and `raw_os_error` returns `self.0`). Only the `unlinkat` half samples behaviour.
5. **`flagged_renames_agree` encodes an errno order the kernel does not promise, and is not
   cfg-gated.** The std reference checks `ENOENT` for a missing source before `EEXIST` for an
   occupied destination. No step has both conditions at once, so this is untested rather than
   wrong. The test is not gated to Linux/Apple either, but on any other unix `renameat_with`
   returns `ENOSYS` by design, so the test would fail there.
6. **`Errno::last` can report errno 0.** `crates/aterm-dirfd/src/unix.rs` `Errno::last` uses
   `unwrap_or(0)`, so a failure with no OS error code would surface as `Err(Errno(0))`. No test
   samples it. `syscall-passthrough` must either rule it out (as a `Sys` axiom that libc sets
   errno whenever it returns -1) or state it.

## 6. Proof order (easiest high-value first)

No spec is blocked by gap 0 alone. Every row needs at least gap 1, because even the flag and
`Errno` newtypes are structs. Three small refactors put the pure core within reach of gaps
1 and 3 only:

1. **`filetype-predicates`** (gaps 1, 3). A `const fn` and one `&` on a `u32` newtype, so it is an
   `omega`/`decide` proof once the newtype carrier is admitted. It is the smallest probe of gap 1
   for this crate, and it backs the kind half of `stats_agree_on_every_field_read_including_inode_identity`.
2. **`flags-bit-algebra`** (gaps 1, 3; plus 2 for `bitor_assign`). Prove `bits`, `|`, `contains` and
   the constant table first; `|=` follows once gap 2 lands. The constant rows can be evaluated per
   platform. With item 1, this certifies every pure fact that the differential tests build on.
3. **The constant half of `errno-constants-and-conversion`** (gap 1). `NOENT.raw_os_error() = ENOENT`
   and its siblings are by definition. Proving them retires the tautological half of
   `the_not_found_errno_is_the_same_constant` (§5.4).
4. **`arg-cstr-faithful`** (gaps 1, 3, 5, 7, 11, 13). This is the highest-value pure spec: it retires
   `an_interior_nul_is_refused_rather_than_truncated` outright, and it is the only way to check the
   heap path (§5.3). Recommendation: factor the body into a monomorphic, closure-free helper,
   `fn c_name<'b>(bytes: &[u8], buf: &'b mut [u8; 512], heap: &'b mut Vec<u8>) -> Result<&'b CStr>`.
   With that, gaps 11 and 13 drop out, and `with_c_str` becomes a one-line wrapper that calls `f` once.
5. **The flag translation in `renameat-with-dispatch`** (gaps 1, 3). Factor
   `fn rename_raw_flags(RenameFlags) -> Option<c_uint>` per cfg (`None` means `ENOSYS`) and prove part (2)
   on it. The syscall and `Sys` halves then wait on gap 8 with the rest.

After gap 8 (platform lane, FFI assumption channel, `unsafe` discharge): `syscall-passthrough` and
`fstat-widening` first. Together they retire 5 tests, and the other effectful specs build on them.
Then the three `Dir` specs, and last `fd-relative-no-reresolution`, which also needs a relational
(two-state) statement over `Sys`.
