# blocks).
#
# NEED rows name what only a person can give. A reader that misses one LOSES
# THE NEED: the person never sees it, and Land lands beside it — a false
# landing, the worst failure. Each must name a need that carries the text
# after `NEED` (case aside), say no `none` (`says_no_needs` false) and land
# nothing.
#
# NONE rows say no need stands. A reader that reads one as a need puts a
# PHANTOM NEED on the person's screen and keeps Land from ever landing: a
# false non-landing. Each must name no need, clear the standing set where it
# holds a NEEDS YOU line (`says_no_needs`), and land.
#
# HEADLESS rows ask the person for something with no NEEDS YOU head (`I need
# you to ...`, `Owner: please ...`). No need is read from them, but Land must
# not land beside one, and its nudge must name what it read open.
#
# FAIL TOWARD A KEPT NEED: a none line is none only where every word of it is
# accounted for. A row labelled NEED below may be one an honest worker meant
# as none but said more than a restatement (`none — the crate was published
# by the release run`): marked DELIBERATE, the reader keeps it, and the
# person reads it.
#
#   NONE || report            no need stands
#   NEED <text> || report     a need, carrying <text>
#   HEADLESS <text> || report an ask with no head: no landing
#   \n                        a line break inside a report
#   # ...                     a comment
