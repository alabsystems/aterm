# LAND DEFENSE TABLE: what Land's strict reading (`clean_defense`,
# `land_open_words` in supervise/policy/turn_end.rs) must make of a reply
# at a land act's yield (FOREVER LAND, owner direction 2026-10-19: "LAND
# EVERYTHING INTO REMOTE MAIN NO EXCEPTIONS").
#
# OPEN rows are defenses that admit a leftover — work not on the remote
# main branch, a wait on a person or a check, a later day, a check that
# could not run, a stopgap, a known issue left — however it is phrased. A
# clean repository probe cannot see any of it, so a reader that calls one
# of these clean LANDS WITH THE LEFTOVER NAMED IN THE DEFENSE ITSELF: the
# worst failure. Each must read open (`clean_defense` false, and
# `land_open_words` names something for the nudge's suffix).
#
# CLEAN rows are honest clean defenses, the hard negations among them
# ("nothing remains", "no review is pending", "the PR was merged"). A
# reader that calls one of these open makes Land nudge forever: the second
# worst failure. Each must read clean.
#
# Rows come from the adversarial reviews of the strict reading (the replies
# that still landed on codex-alab 15dbc93c4, codex-alab 4daeee9da's rows and
# their negative controls, and the false positives those rows produced),
# from the defenses this repository's own tests and labs give, and from the
# word families of the review brief, phrased many ways. They are behaviour:
# what a defense says, never how aterm words anything.
#
#   == open  /  == clean     the rows that follow, one defense a line
#   \n                       a line break inside a defense
#   # ...                    a comment (the family a run of rows exercises)
