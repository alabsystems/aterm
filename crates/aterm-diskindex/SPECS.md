# aterm-diskindex: the disk index's model

The rows of docs/DESIGN-disk-map-2026-11-18.md §3.2 and the proof rules of §6.1, as a pure
library: nothing here reads a disk (the walker that fills an `Index` is DC-33). None of
these specs is proved; the one fixture test samples each, with a mutant that fails each rule.
