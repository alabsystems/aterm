Version 1.00 (November 1, 2014) — name table says "Typeface © (your company).

Mario Kart F2 is the community fan font of the Mario Kart title lettering,
distributed free for personal use on font aggregator sites (fontmeme.com,
onlinewebfonts.com and mirrors).

REDISTRIBUTION NOTICE — READ BEFORE SHIPPING A RELEASE
------------------------------------------------------
Same posture as Super Mario 256 before it: a free personal-use fan font with NO
license file, no OFL/Apache grant, and no stated route to a redistribution
agreement — plus lettering that evokes a Nintendo property. Embedding these
bytes in the aterm binary IS redistribution. Resolve this with the author
before the asset ships in a cut release; if it cannot be resolved, drop the
`mariokart` entry or return to an open-licensed lookalike (the retired Titan
One, OFL-1.1, was one).

COVERAGE
--------
Unlike Super Mario 256 (which lacked & ` { } ~), Mario Kart F2 covers ALL 94
printable ASCII characters — nothing in ordinary shell text falls through to
the fallback face.
