# aterm

AI Terminal: inspired by Ghostty, designed for AI.

aterm is made by [ALab](https://alab.systems). Its source code is not published:
this repository carries aterm's binary releases, their release notes, and its
license.

## Install

Install the signed, notarized macOS app with Homebrew:

```sh
brew install --cask alabsystems/tap/aterm
```

or run its installer, which verifies the signed release before it installs it:

```sh
curl -fsSL https://alab.systems/install.sh | bash
```

or download `aterm.dmg` from the newest release. aterm updates itself.

Every release is listed under [Releases](https://github.com/alabsystems/aterm/releases),
and its notes are in `release-notes/`.

## Security

Report a security problem privately to hello@alab.systems, not in a public
issue.
